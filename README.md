# Special Car — Seguimiento comercial de vehículos

CRM liviano para el equipo comercial: leads con # consecutivo, estados hasta la entrega, gestiones con recordatorios en el calendario de cada comercial, cotizaciones en PDF, reportes y acceso con el correo personal de cada asesor.

Abrir `index.html` sin configurar nada inicia el **modo demo** (código `123456`). Instalación con Google Apps Script: ver [VENTAS_SETUP.md](VENTAS_SETUP.md).
